# library/curated/en/B1

Curated, human-reviewed Cambridge B1 Preliminary batches (Reading/Listening/Writing/Speaking)
land here, mirroring `library/curated/de/B1`. Files are `curated_en_B1_<hash>.json` produced by
the generation + gate pipeline (Etapa 1+). This directory existing (even empty) lets
`fill:pool --lang en --level B1` resolve instead of erroring "Missing curated dir".

Format per Part: see `library/blueprints/cambridge_B1.json` and `../../../../plantillas-en-b1/`.
